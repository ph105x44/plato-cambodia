PLATO ESTATE

Откройте index.html — сайт со встроенным квизом.
Компьютерная и телефонная версии работают в одном комплекте файлов.
При загрузке на хостинг сохраняйте структуру папки assets.

Имя и номер телефона обязательны при любом выбранном способе связи.

Подключение заявок
В assets/config.js укажите адрес обработчика в leadEndpoint.
Он принимает POST JSON и возвращает {"ok":true} после принятия заявки.
Пока обработчик не подключён, сайт предлагает отправить подготовленный запрос через мессенджер.
Поля заявки: name, contact (номер телефона), channel, location, answers, consent, website, elapsed, utm, referrer.

Перед размещением заполните реквизиты в privacy.html и consent.html.
Для индексации главной страницы снимите noindex,nofollow после запуска.
